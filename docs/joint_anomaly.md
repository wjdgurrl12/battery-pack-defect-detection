# 조합 이상 탐색 실험

`diagnostics.md`의 후속 실험이다.

앞선 진단에서 셀 위치·시간 구조·온도 관계·모듈 위치 네 방향을 모두 뒤졌고 전부 "구조 없음"이 나왔다.
**단 하나 남은 미탐색 영역**이 조합 이상이었다.

> **조합 이상**: 개별 피처는 전부 임계 아래인데, 여러 개가 동시에 조금씩 어긋나 있는 경우.
> 예 — 셀이 5 mV 낮고(정상 범위), 그 모듈이 8 mV 낮고(정상 범위), 온도도 0.5 °C 높다(정상 범위).
> 각각은 괜찮지만 **셋이 겹친 것**이 이상하다.

이것이 원래 딥러닝의 가장 강한 명분이었다. 개별 임계는 구조적으로 이런 조합을 볼 수 없고,
다변량 모델만이 "이 값이면 저 값도 이래야 한다"를 배울 수 있기 때문이다.

**결론부터: 이 데이터에 조합 이상은 존재하지 않는다. 그리고 그 이유가 구조적이다.**

---

## 1. 실험 설계

### 셀 하나를 6개 숫자로 표현한다

셀마다 아래 6개 값을 뽑는다. 충전 전반 35% 구간과 후반 35% 구간의 평균을 쓴다.

| # | 피처 | 정의 |
|---|---|---|
| 1 | 셀잔차 | 충전 후반, 같은 모듈 중앙값 대비 이 셀의 편차 |
| 2 | SOC증가분 | 피처1의 (후반 − 전반) — SOC에 따라 얼마나 벌어졌나 |
| 3 | 좌인접차 | 모듈 내 왼쪽 셀과의 차 |
| 4 | 우인접차 | 모듈 내 오른쪽 셀과의 차 |
| 5 | 모듈편차 | 소속 모듈의 편차 (모듈 중앙값 − 전체 모듈 중앙값) |
| 6 | 모듈온도 | 소속 모듈의 온도 잔차 |

```
M07CV04 → (-2.1, -1.4, 0.8, -0.3, -15.2, 0.05)
```

셀 하나가 좌표 6개를 가진 점이 된다.
30팩 × 176셀 = **5,280개 점**이 6차원 공간에 놓인다.

피처 1~4는 셀 수준, 5~6은 모듈 수준의 정보다.
**의도적으로 서로 다른 계층을 섞었다** — 조합 이상은 계층을 넘나들 때 생기기 때문이다.

### 두 검출기를 비교한다

| | 방식 | 조합을 보는가 |
|---|---|---|
| **개별 최대** (baseline) | 6개 피처 각각의 로버스트 z 중 최댓값 | ❌ |
| **조합** (마할라노비스) | 6차원 공분산을 반영한 거리 | ✅ |

둘 다 팩 점수는 176셀 중 최댓값. 임계는 오탐 3%(정상 30팩 중 2번째로 높은 값).
공분산은 **채점 대상 팩을 제외한 29팩**으로 추정한다 (leave-one-pack-out).

## 2. 정상 데이터의 구조

먼저 조합할 여지가 있는지부터 확인한다. 피처들이 서로 독립이면 다변량 모델이 이길 수 없다.

### 상관행렬 (5,280 셀)

| | 셀잔차 | SOC증가분 | 좌인접차 | 우인접차 | 모듈편차 | 모듈온도 |
|---|---|---|---|---|---|---|
| **셀잔차** | 1.00 | **0.96** | 0.73 | 0.74 | −0.06 | −0.01 |
| **SOC증가분** | 0.96 | 1.00 | 0.70 | 0.70 | −0.06 | −0.01 |
| **좌인접차** | 0.73 | 0.70 | 1.00 | 0.60 | 0.00 | 0.00 |
| **우인접차** | 0.74 | 0.70 | 0.60 | 1.00 | −0.00 | −0.00 |
| **모듈편차** | −0.06 | −0.06 | 0.00 | −0.00 | 1.00 | −0.04 |
| **모듈온도** | −0.01 | −0.01 | 0.00 | −0.00 | −0.04 | 1.00 |

두 덩어리로 확연히 갈린다.

**① 셀 수준 피처 4개는 서로 강하게 상관한다 (0.60~0.96).**
특히 셀잔차와 SOC증가분은 0.96으로 거의 같은 값이다.

**② 모듈 수준 피처 2개는 나머지 전부와 상관이 0이다.**
모듈편차와 다른 피처의 상관이 −0.06 이하, 모듈온도는 −0.01 이하다.

### 고유값

```
3.23  1.04  0.97  0.40  0.34  0.03
     (완전 독립이면 전부 1.00)
```

마지막 **0.03**이 눈길을 끈다.
정상 점들이 6차원 공간에서 **한 방향으로는 거의 움직이지 않는다**는 뜻이다.
3차원으로 비유하면 공 모양이 아니라 **종잇장처럼 납작하게 눌려 있다.**

그 방향으로 조금만 벗어나도 크게 티가 나므로, 이론적으로는 강력한 검출 축이 된다.
마할라노비스 거리가 정확히 이런 축을 활용하는 방법이다.

**→ 조합할 여지가 있어 보인다. 실제로 되는지 재본다.**

## 3. 결과

정상 30팩 기준: 개별 최대 중앙 5.3 / 임계 7.7, 조합 중앙 5.5 / 임계 7.9

| 주입 | **개별 최대** | **조합** |
|---|---|---|
| **단독 이상** | | |
| 셀 5 mV | 4% | 5% |
| 셀 8 mV | 3% | 4% |
| 셀 12 mV | 6% | 8% |
| 셀 20 mV | **79%** | 48% |
| 모듈 8 mV | 11% | 6% |
| 모듈 12 mV | 16% | 7% |
| 모듈 20 mV | **77%** | 9% |
| **약한 이상 동시 발생** | | |
| 셀5 + 모듈8 | **11%** | 6% |
| 셀5 + 모듈8 + 온도0.5 | **12%** | 7% |
| 셀8 + 모듈12 | **18%** | 6% |

**조합이 이긴 경우가 하나도 없다.**
단독 이상에서는 크게 지고(모듈 20 mV에서 77% → 9%),
조합을 노린 시나리오에서도 전부 진다.

## 4. 왜 졌는가

### 납작한 판이 함정이었다

마할라노비스 거리는 **정상 데이터가 안 움직이는 방향에 큰 가중치**를 준다.
고유값 0.03 방향이 그것이었는데, 확인해보니 그 방향은
**셀잔차와 SOC증가분의 중복(상관 0.96)** 이 만든 것이었다.

물리적 관계가 아니다. 같은 값을 두 번 센 것뿐이다.

```
피처1 = 후반 셀잔차
피처2 = 후반 셀잔차 − 전반 셀잔차     ← 후반 성분이 이미 피처1에 있음
```

모델은 "이 두 피처는 항상 같아야 한다"를 열심히 학습했고,
그건 고장 검출에 아무 쓸모가 없다.

### 진짜 신호가 눌렸다

용접불량의 신호인 **모듈편차는 다른 피처와 상관이 0이다** (−0.06, −0.04).
마할라노비스는 상관 구조에 가중치를 배분하는데, 상관이 없는 축에는 가중치가 붙지 않는다.

결과적으로 모델이 중복 축에 힘을 쏟느라 **실제 고장 축의 신호를 눌러버렸다.**
모듈 20 mV 검출률이 77% → 9%로 무너진 것이 그 결과다.

### 근본 원인 — 상관 0이면 조합할 것이 없다

조합 이상이 성립하려면 **"이 값이면 저 값도 이래야 한다"** 는 관계가 있어야 한다.
모듈편차와 모듈온도는 나머지 전부와 상관이 0이므로 그런 관계가 애초에 없다.
각각을 따로 보는 것 외에 할 수 있는 일이 없다.

## 5. 구조적 이유 — 전처리를 잘한 대가

이 결과는 STEP 2의 계층 분해에서 이미 예정되어 있었다.

```
cell_dev = cell_res + mod_dev
   셀 편차   모듈기준 잔차   모듈 편차
```

이 분해가 팩·모듈·셀 성분을 **서로 겹치지 않게 갈라놓았다.**
겹치지 않으니 상관이 0이고, 상관이 0이니 조합할 여지가 없다.

> **각 계층을 따로 보는 것이 이미 최적이다.**
> 물리 구조를 충실히 벗겨낸 대가로 조합의 여지가 사라졌다.

전처리가 부실했다면 성분들이 서로 섞여 있었을 것이고,
그랬다면 다변량 모델이 그 얽힘을 풀어내며 이득을 봤을 것이다.
**전처리가 잘돼 있어서 모델이 할 일이 없어진 역설적 상황이다.**

## 6. 종합 — 다섯 방향 전부 같은 답

| 탐색 방향 | 측정 | 결과 |
|---|---|---|
| 셀 위치 구조 | 팩쌍 프로파일 상관 0.002 | 없음 |
| 시간 구조 | 궤적 스칼라 근사 R² 0.923 | 거의 없음 |
| 온도–전압 관계 | R² 0.001 | 없음 |
| 모듈 위치 구조 | 팩쌍 상관 0.033 | 없음 |
| **조합 구조** | **조합이 개별보다 전부 나쁨** | **없음** |

**모델이 학습할 구조가 데이터에 남아 있지 않다.**

이것은 실패가 아니라 **측정된 사실**이다.
이 데이터의 이상 신호는 물리 분해 후 단순한 형태로 남고,
로버스트 통계가 이미 그것을 최적으로 다루고 있다.

## 7. STEP 6에 대한 함의

딥러닝은 프로젝트 요건이므로 그대로 진행한다. 다만 **기대치를 미리 정직하게 설정한다.**

### 예상 결과

AE의 성능은 baseline과 비슷하거나 다소 낮을 것이다.
근거는 위 다섯 방향의 측정 결과다.

### 그래서 이렇게 진행한다

| 항목 | 방침 |
|---|---|
| AE 입력 | SOC 격자 127칸으로 재배열 (팩마다 행 수가 687~963으로 다르므로) |
| 채점 | baseline과 **동일한 주입 실험**으로 나란히 평가 |
| 임계 | 오탐 3% 운영점 공통 적용 |
| 검증 분할 | 팩 단위 leave-one-pack-out |
| 보고 | 결과가 비슷하게 나오면 그대로 보고 |

### 보고할 결론의 형태

> "물리 기반 전처리를 충실히 수행하면 딥러닝과 로버스트 통계의 성능이 수렴한다.
> 본 진단 실험은 그 원인을 다섯 방향에서 측정으로 확인했다."

이 주장은 근거가 있고 검증 가능하다.
모델 성능만 제시하는 것보다 오히려 설득력이 높다.

## 8. 이 실험의 한계

| 항목 | 내용 |
|---|---|
| 피처 6개는 임의 선택 | 다른 피처 조합에서는 상관 구조가 다를 수 있다 |
| 피처 1·2 중복 | 설계 실수. 재시도한다면 SOC증가분을 셀잔차와 직교하게 정의해야 한다 |
| 마할라노비스는 선형 | 비선형 관계는 볼 수 없다. AE가 이 부분을 확인해줄 것이다 |
| 팩 30개 | 6×6 공분산 추정에는 충분하나, 오탐 3%의 신뢰구간은 여전히 0.1~17%로 넓다 |

**피처 1·2의 중복은 이 실험에서 실제로 해를 끼쳤다.**
다음 실험에서 피처를 설계할 때는 상관행렬을 **먼저** 확인하고 중복을 제거해야 한다.

## 9. 재현

```python
# 셀 176개 × 피처 6개
def feats(V, T, soc):
    g  = V.reshape(-1, 16, 11)
    cr = (g - median(g, axis=2)) * 1000            # 모듈기준 셀잔차
    md = (median(g,2) - median(median(g,2),1)) * 1000
    Tm = T.reshape(-1,16,2).mean(2); Tr = Tm - Tm.mean(1)

    n = len(V); lo = slice(0, int(n*.35)); hi = slice(int(n*.65), None)
    c_hi = cr[hi].mean(0); c_lo = cr[lo].mean(0)
    L[:,1:]  = c_hi[:,1:]  - c_hi[:,:-1]           # 좌인접차
    R[:,:-1] = c_hi[:,:-1] - c_hi[:,1:]            # 우인접차
    return stack([c_hi, c_hi-c_lo, L, R,
                  repeat(md[hi].mean(0)), repeat(Tr[hi].mean(0))])

# 공분산은 채점 대상 팩을 제외한 29팩으로 추정
# z 클리핑 ±5, 대각 정규화 1e-3 (수치 안정성)
```
